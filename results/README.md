# Results

This directory contains compact paper-facing summaries for the main comparison, component ablations, and parameter sensitivity analysis.

The ablation summary uses the complete frozen S41 200-sample slice for each of MATH, SVAMP, and MultiArith. The reported percentages are computed as the number of correct predictions divided by 200; failed samples remain part of the denominator.

The full implementation, raw traces, and scripts used to regenerate these summaries will be released upon acceptance.
